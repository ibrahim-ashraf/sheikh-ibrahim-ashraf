سياسة الخصوصية

توضح هذه السياسة المعلومات التي يتعامل معها تطبيق الشيخ إبراهيم أشرف والخدمات المستخدمة عند تسجيل الدخول واستخدام ميزات التطبيق.

البيانات التي نجمعها

  • معلومات تسجيل الدخول: عند استخدام خدمة تسجيل الدخول عبر Google، نحصل على:
    • اسم المستخدم
    • البريد الإلكتروني
    • الصورة الشخصية (إن وجدت)
  • عند تسجيل الدخول باستخدام Google، يتلقى التطبيق معرّف الحساب والاسم والبريد الإلكتروني والصورة الشخصية إن توفرت. تُحفظ بيانات الملف الشخصي ورمز تسجيل الدخول محلياً على الجهاز.
  • إذا كانت الإشعارات مفعّلة، ينشئ التطبيق رمز إشعارات Expo ويحفظه في Firestore مع معرّف المستخدم واسمه وبريده الإلكتروني وتاريخ آخر تحديث للسجل لتوجيه الإشعارات إلى الجهاز.
  • يحفظ التطبيق محلياً تفضيل المظهر وبعض بيانات تشغيل التطبيق، مثل عدد مرات الفتح وحالة عرض طلب التقييم.
  • يتصل التطبيق بخدمة YouTube لطلب بيانات القناة والفيديوهات وقوائم التشغيل، وبخدمة GitHub Pages للتحقق من بيانات إصدار التطبيق.

استخدام التطبيق

  • يستخدم التطبيق YouTube Data API لجلب بيانات القناة والفيديوهات وقوائم التشغيل، ويعرض الفيديوهات باستخدام مشغل YouTube.
  • عند البحث عن فيديو، يُرسل نص البحث إلى YouTube Data API لتنفيذ البحث.
  • عند مشاركة فيديو، نستخدم رابط YouTube الأصلي للفيديو.
  • عند فتح روابط التواصل الاجتماعي، سيتم توجيهك لمتصفح الويب.

الأذونات المطلوبة

  • INTERNET: للوصول إلى محتوى القناة والخدمات المختلفة.
  • يتطلب التطبيق اتصال الإنترنت لعرض المحتوى والتحقق من تحديثات التطبيق وخدمات تسجيل الدخول والإشعارات.
  • قد يطلب التطبيق إذن الإشعارات لإرسال تنبيهات الفيديوهات الجديدة وتحديثات التطبيق، ويمكن رفض الإذن.

الخدمات الخارجية

  • YouTube: لطلب وعرض محتوى القناة والفيديوهات، وفقاً لشروط وسياسة خصوصية Google وYouTube.
  • Google Sign-In: للمصادقة وإتاحة بيانات الملف الشخصي التي يختار المستخدم مشاركتها عند تسجيل الدخول.
  • Firebase Firestore: لحفظ بيانات الحساب ورمز إشعارات الجهاز عند تفعيل الإشعارات.
  • Expo Push Notifications: لإنشاء رمز الإشعارات وتوفير خدمة إرسال الإشعارات.
  • GitHub Pages: لاستضافة ملف معلومات إصدار التطبيق الذي يقرأه التطبيق للتحقق من التحديثات.

التخزين المحلي

  • نخزن البيانات التالية محلياً على جهازك:
    • إعدادات المظهر (الوضع الليلي/النهاري)
    • معلومات تسجيل الدخول
    • رمز تسجيل الدخول وبيانات الملف الشخصي
    • تفضيل المظهر وبيانات تشغيل التطبيق اللازمة لميزات مثل عدّ مرات الفتح والتقييم
  • يمكنك تسجيل الخروج لإزالة بيانات تسجيل الدخول والملف الشخصي المحفوظة محلياً، أو مسح بيانات التطبيق من إعدادات الجهاز. ولا يعني تسجيل الخروج وحده حذف البيانات المحفوظة في Firestore.

حماية الخصوصية

  • تُرسل بيانات الحساب ورمز الإشعارات إلى Firebase Firestore عند استخدام الميزات الموضحة أعلاه، كما تتلقى Google بيانات المصادقة وطلبات YouTube اللازمة لتقديم خدماتها.
  • تخضع معالجة البيانات لدى الخدمات الخارجية لسياسات مزوديها. لا يحدد التطبيق مدة احتفاظ موحدة للبيانات المخزنة لدى تلك الخدمات.
  • يمكن طلب حذف الحساب عبر صفحة حذف الحساب.
